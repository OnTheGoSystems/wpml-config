# This repository is archived

The language configuration files that WPML downloads are no longer published from this repository, and it no longer accepts changes.

- **Plugin and theme authors:** to add or change the language configuration file of your plugin or theme, follow [Contributing wpml-config files](https://wpml.org/documentation/support/language-configuration-files/contributing-wpml-config-files/).
- **WPML team:** the files now live at [git.onthegosystems.com/wpml/wpml-config](https://git.onthegosystems.com/wpml/wpml-config). Open a merge request there.

To learn how language configuration files work, see [Language configuration files](https://wpml.org/documentation/support/language-configuration-files/).

The history up to the move stays here for reference.
